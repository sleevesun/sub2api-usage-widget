# Sub2API Usage v0.4.1

- 设置图标新增更新角标，主面板显示新版本提示；点击后直接定位到设置中的应用更新区域。
- 应用启动后检查更新，运行期间每三十分钟复查；检查失败后五分钟重试，回到前台或网络恢复时也会按间隔复查。
- 更新检查失败时显示明确的提示与重试入口；已发现的新版在后续网络检查失败时继续保留。
- 更新仍由用户点击后下载和安装；后台复查不会打断下载、安装或重启。
- 更新提示适配窄窗口及浅色、深色主题，保持现有账号配置、更新地址和签名公钥。

绿色版：下载 `Sub2API-Usage_0.4.1_x64-portable.exe`，直接运行，无需安装。

更新提醒改进在升级至 v0.4.1 后生效，用于发现后续版本。v0.3.0、v0.4.0 仍可通过设置中的“检查更新”升级。

模型消费 TPS 保留真实缺失状态：当前用量接口未提供模型速度，显示“—”，没有用全局耗时或社区速度推算。
