# Sub2API Usage v0.4.3

- Codex Radar 的矩阵和排名支持 GPT-6.2 系列，同时保留 GPT-6 和 GPT-6.1。排名仍默认筛选「智商 > 90」。
- 从本版开始，Windows 绿色版在线更新会下载并验证签名，在原路径替换 EXE，然后从同一路径重启。程序目录需要可写；原文件名、快捷方式及账号配置可继续使用。

绿色版请下载 `Sub2API-Usage_0.4.3_x64-portable.exe`，无需安装。v0.4.2 及更早版本的在线更新仍使用兼容安装器。若要让旧绿色版在原路径切换到本版，请先退出旧版，再用本版绿色 EXE 替换旧 EXE 并沿用旧文件名。此后可以直接在 App 内更新。
