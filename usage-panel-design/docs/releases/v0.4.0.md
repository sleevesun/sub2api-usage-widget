# Sub2API Usage v0.4.0

- Codex Radar 正式集成：默认矩阵视图，支持排名视图和展开看板，沿用浅色与深色主题。
- 匿名读取 Codex Radar 官网的整轮测试数据，动态展示 GPT-6、GPT-6.1 系列的各推理档位、Bench 得分、估算费用与分钟耗时。
- 增加纯智商榜、性价比榜、效率榜，每榜最多五项；默认勾选“智商 > 90”，可取消筛选。
- 区分待评分和无此档位，展示北京时间测试完成时间；十分钟整轮缓存，手动刷新失败时保留上轮数据。
- 模型消费表在 Token 后新增 TPS。当前接口未提供模型 TPS，显示“—”，不使用全局耗时推算。
- 改善窄窗口的矩阵、排名和消费表布局。

Bench 满分为 150。“智商”仅为 Bench 得分的通俗叫法，并非人类 IQ。数据来自 Codex Radar 作者公开测试，费用为估算值。

绿色版：下载 `Sub2API-Usage_0.4.0_x64-portable.exe`，直接运行，无需安装。

v0.3.0 用户可在设置中检查更新，使用同一签名公钥验证的更新安装器升级。账号配置位置与更新地址保持不变。
