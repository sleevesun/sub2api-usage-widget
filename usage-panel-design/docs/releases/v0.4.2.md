# Sub2API Usage v0.4.2

- 模型消费表接入“本机 Codex 参考 TPS”，按所选时段、精确模型名称汇总，显示速度及有效样本量。
- 在模型消费表下展开“本机 Codex TPS”，点击“启用本机 TPS”，重启 Codex 后开始记录新请求。仅 App 运行时采样，不补算历史记录。
- 速度按输出 Token 总量除以请求总耗时计算，包含网络与首字等待；跳过失败、不完整、歧义及可识别工具活动的请求。当前支持 HTTP/SSE，WebSocket 请求暂不计入。
- 采样仅监听本机并保存模型、Token 和计时，不保存对话正文；保留 35 天。关闭采样可恢复由此修改的 Codex 配置，已有其他遥测目标时不会替换。
- 悬浮球拖动改由 Windows 原生窗口移动处理，消除逐次移动请求排队造成的鼠标跟随延迟。
- 修复快速拖动并松手后，下一次点击被吞掉或悬浮球跳动的问题。
- 区分拖动、单击、右键和取消操作，避免拖动取消或窗口失焦时误打开主面板。
- 支持负坐标显示器上的拖动起点，并按系统设置识别鼠标主键。

绿色版：下载 `Sub2API-Usage_0.4.2_x64-portable.exe`，直接运行，无需安装。

v0.4.1 可通过更新提醒进入设置升级；v0.3.0、v0.4.0 可在设置中点击“检查更新”。更新继续使用现有签名公钥及更新地址。

TPS 是本机 Codex 的客户端参考吞吐率，与账号在其他设备、其他客户端产生的消费范围可能不同。没有对应有效样本时显示“—”。
